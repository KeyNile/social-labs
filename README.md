# 서울청년패널 × Nemotron — 페르소나 기반 정책 시뮬레이션 (설계 문서)

`social-labs`의 페르소나 엔진을 미국 **NLSY97** 패널에서 **한국 데이터**로 이식하기 위한 구현 계획 모음입니다. 최종 설계는 **2계층 페르소나** 구조입니다.

- **정적 페르소나 (Static)** — `NVIDIA Nemotron-Personas-Korea` (합성 스냅샷, 폭·대표성)
- **디지털 트윈 (Generative)** — `서울청년패널` 실데이터 (1·2차 궤적 + 정책 이용/만족, 깊이·인과 근거)
- 두 계층을 결합해 **정책효과 시뮬레이션**을 수행

> 핵심 원칙: 정책효과의 *근거는 디지털 트윈(실데이터)에서만* 나오고, 정적 페르소나는 그 패턴을 *투영(projection)받아 모집단으로 확장*하는 역할로 한정한다.

## ⚠️ 데이터에 관하여 (중요)

**원자료(서울청년패널 `.dta`, 코드북 `.csv`)는 이 저장소에 포함하지 않습니다.** 아래 이유로 공개 리포지토리에 올리지 않는 것을 강력히 권장합니다.

1. **이용약관**: 서울청년패널 마이크로데이터는 제공기관(서울연구원/서울시)의 데이터 이용 협약에 따르며, 통상 **재배포·공개 게시가 제한**됩니다. 공개 업로드는 약관 위반 소지가 큽니다.
2. **개인정보(PIPA)**: 비식별 처리되었더라도 실제 응답자 마이크로데이터의 공개 게시는 재식별 위험이 있습니다.
3. **용량**: `.dta`가 약 94MB로 GitHub 권장 한도(50MB 경고/100MB 제한)에 근접 — 올리더라도 Git LFS가 필요합니다.

### 권장 방식
- `.gitignore`로 데이터 파일을 추적에서 제외 (이 브랜치에 포함).
- 데이터 획득 경로를 문서로 안내(아래), 로컬/비공개 스토리지에 보관.
- 필요하면 **합성 미니 샘플**(수십 행, 값 라벨만)로 파이프라인 테스트용 픽스처를 별도 작성.

### 데이터 배치 규약 (로컬)
```
data/                      # .gitignore 처리 (커밋 금지)
├── seoul_youth_panel/
│   ├── merged_w1w2.dta     # 서울청년패널 1-2차 머지 (제공기관에서 획득)
│   └── codebook.csv        # 코드북 (값 라벨)
└── nemotron_personas_korea/  # HuggingFace에서 로드: nvidia/Nemotron-Personas-Korea
```
